# Nexus Mods listing — pre-publication draft

**Title:** XB77 Red Sun OpenMW — High-Contrast Dialogue Selector (Windows x64)

**Summary:** Accessibility-oriented modified OpenMW build with highlighted NPC dialogue focus, readable topic colors, native controller support and portable Windows first-run setup.

## Description

XB77 Red Sun OpenMW enhances readability in The Elder Scrolls III: Morrowind by adding a thin yellow focus outline and arrow around the active NPC dialogue topic. Available topics use a light cobalt color, while exhausted topics are displayed in grey. A native Options → Prefs setting enables or disables the custom visual treatment.

Native OpenMW Xbox menu navigation is supported alongside keyboard and mouse operation. The planned Windows package is a standalone customized OpenMW distribution, **not an ESP/ESM data-only mod**.

## Installation

After a verified public ZIP becomes available, extract it into a new directory, run the built-in Windows first-time setup wizard, point it at your legally installed Morrowind Data Files, then launch `openmw-launcher.exe`. Do not replace another OpenMW installation.

## Requirements

- Legally owned Morrowind game data, including `Morrowind.esm` and `Morrowind.bsa`
- Windows 64-bit
- No separate OpenMW installation required for the eventual standalone package
