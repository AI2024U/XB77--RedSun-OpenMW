# XB77 Red Sun OpenMW — public-safe development status (2026-11-23)

**Status:** Active accessibility-focused OpenMW engineering; **not a certified public executable release**.

XB77 Red Sun targets an independent Windows portable OpenMW 0.52.0 RC1 development baseline. Work includes higher-contrast NPC dialogue topics, a native player-accessibility toggle, controller focus/navigation, portable configuration and custom in-world subtitle presentation.

Recent gameplay feedback indicates improvements to dialogue and subtitle readability in development tests. This does **not** establish a ready-to-redistribute clean-install Windows build.

## Public release blockers
- Fresh Windows 10/11 first-run GUI verification from directly opened EXE / launcher / wizard, without scripts or profile leakage
- End-to-end save/settings/log/screenshot isolation and 3D game-world verification
- Regression-proof native keyboard/mouse/Xbox interactions, NPC dialogue focus/toggle and movie/cutscene subtitle exclusions
- Verified legal distribution of assets, third-party runtime libraries and compatible licenses
- Complete corresponding GPLv3 modified OpenMW source matching distributed binaries, published checksums, privacy/source review
- Independent clean-machine gameplay acceptance and accurate unsigned/signed designation

**Privacy and licensing:** Do not upload personal logs/media/paths, secret keys, private repository details or proprietary Morrowind/Tribunal/Bloodmoon game assets. Documentation updates are not executable releases and do not certify a successful build.
