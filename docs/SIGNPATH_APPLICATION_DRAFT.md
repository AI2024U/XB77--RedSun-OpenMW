## Short project description

XB77 Red Sun OpenMW is an independent, free, accessibility-focused Windows modification of the OpenMW engine for players of The Elder Scrolls III: Morrowind. It introduces a high-contrast yellow NPC dialogue selection outline and pointer, cobalt-blue available topics, grey exhausted topics, a native ON/OFF option, and Xbox controller navigation. It is designed for a standalone portable installation. No proprietary Morrowind game assets are included; each player must legally own Morrowind.

## Why we seek free signing

We want users to verify that a downloadable Windows release matches our public, reviewed, automated source build. We are seeking a trustworthy publisher signature rather than asking players to disable Windows security features or bypass warnings. The mod is noncommercial and intended to improve accessibility.

## Upstream-derived code disclosure

XB77 modifies upstream OpenMW executables. We have **not yet confirmed** that upstream publishes authenticode-signed Windows binaries, that our public repository qualifies as a visible upstream fork, or that the release branch descends from normally signed upstream branches. We request explicit eligibility guidance; we do not represent ourselves as eligible now.

## Security and maintenance

The public repository identifies maintainer roles, a proposed code-signing policy, data handling, release review requirements, and common privacy leaks. The current automated source safeguards passed, but the full public source-to-binary build and independent runtime audit remain incomplete.
