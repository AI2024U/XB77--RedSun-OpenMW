# Security policy

## Current support status

**Pre-release; no supported signed public binaries.** The private development ZIP is not an approved public release.

## Reporting

Use GitHub's **Report a vulnerability / private security advisory** functionality if available, or request a private contact method from the maintainer. Do not disclose passwords, private logs or sensitive paths in public issues.

## Release integrity

- Never disable Microsoft Defender or SmartScreen as a condition of using XB77.
- Authenticity requires a public build linked to exact source, recorded SHA-256 checksums and verified signatures where applicable.
- The project does **not** claim that a self-signed certificate removes SmartScreen warnings.
- The eventual public wizard should only modify the selected XB77 portable folder and should validate Morrowind assets before updating configuration.
- Review any third-party libraries, build steps, or assets before publishing.
