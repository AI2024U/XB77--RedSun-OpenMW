# Contributing

Thank you for improving dialogue accessibility in XB77 Red Sun OpenMW.

- This is an OpenMW-derived GPLv3 project. All submitted changes must have compatible rights and license notices.
- Propose changes through GitHub Issues and pull requests; explain gameplay impact and include test steps.
- Do not upload Morrowind game assets, copyrighted screenshots/backgrounds without redistribution permission, third-party binaries of uncertain origin, credentials, personal files, gameplay logs or Windows user paths.
- Use GitHub's private email / noreply commit author address and review your author name before committing.
- Commits and pull requests must be reviewed for source integrity, privacy, accessibility regression, and provenance.
- Never request code-signing secrets in an issue. Signed releases require explicit maintainer approval and verified automated builds.
